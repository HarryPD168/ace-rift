# 王牌裂隙（Ace Rift）· 第一關「撕角廣場」

2D 橫版冒險，戰鬥由撲克牌型驅動。本專案依設計文件實作完整第一關，可在現代瀏覽器直接遊玩，支援電腦與手機／平板（直向、橫向）。

設計文件（請勿覆蓋）：`ace-rift-design.docx`

## 如何開始

線上遊玩：

- [GitHub Pages](https://harrypd168.github.io/ace-rift/)
- 備用：[jsDelivr](https://cdn.jsdelivr.net/gh/HarryPD168/ace-rift@main/index.html)

原始碼：<https://github.com/HarryPD168/ace-rift>

本機也可直接開。建議用本機伺服器（避免部分瀏覽器限制）：

```bash
cd /workspace/ace-rift
python3 -m http.server 8080
```

然後在瀏覽器打開：<http://localhost:8080>

也可以直接用瀏覽器開啟 `index.html`（無需建置）。首次點擊畫面會取得焦點並開啟音效。

## 操作

### 鍵盤與滑鼠（電腦）

| 按鍵 | 功能 |
|------|------|
| ← / →（或 A / D） | 左右移動。以方向鍵為主 |
| ↑（或空白鍵、W） | 跳躍。按住可跳得更高 |
| ↓（或 E、S） | 互動，例如開啟寶箱 |
| 1–5 或滑鼠點選 | 選擇手牌（可多選） |
| J、F、Enter 或「出牌」按鈕 | 出牌。未選牌時打出最左側（最上面）一張，作為單張 |
| T 或「洗牌」按鈕 | 把手牌與棄牌洗回牌庫，再抽滿 5 張 |
| Q 或「百搭」按鈕 | 武裝百搭（每場戰鬥 3 次），可當作任意花色／點數 |
| K 或點擊牌力槽 | 牌力值滿時發動 Joker Time |
| Esc | 暫停 |
| M | 靜音 |
| R | 死亡後從檢查點重試 |
| H | 開啟操作說明（標題畫面或遊戲中皆可） |

### 觸控（手機、平板）

觸控按鈕會在觸控裝置、較窄螢幕，或實際使用觸控時出現；用鍵盤遊玩的寬螢幕電腦預設會隱藏。

- **左側**：圓形方向鍵（可按住或滑動；上為跳躍，下為互動，左右移動）。搖桿會留在螢幕安全區內，不會超出畫面
- **右側**：「跳」（按住可跳得更高）、「出牌」、「互動」（開寶箱）、「洗牌」、「百搭」、「Joker」（牌力值滿時會提示）
- **手牌**：畫面下方的卡牌可點擊多選，目標足夠大，適合拇指
- **上方**：暫停、靜音、說明；死亡後可點「重試」
- 直向遊玩時，遊戲畫面在上、控制與手牌在下，避免擋住中央動作
- 橫向遊玩時，控制以半透明方式放在左右下角，手牌在底部中央

標題、說明與開場在較小的直向畫面上會改以網頁文字顯示，方便閱讀與點按。

## 牌型效果

- **單張**：基礎斬擊；黑桃會射出尖刺，可刺破黑桃障礙與激活黑桃樁
- **對子**：身前雙重長距突刺，穿透並眩暈 1.5 秒，可打斷蓄力；出牌時角色不會位移
- **三條**：前方扇形三發彈幕
- **順子**（3 張以上連續點數）：站立多段連斬，攻擊時不會位移。缺口請藉碎牌平台跳躍通過；隱藏凹室可從踏腳平台向上跳入
- **同花**（3 張以上同花色）：黑桃箭雨（破盾、清場）、紅心吸血光環、梅花毒霧、方塊護盾
- **葫蘆／鐵支／同花順**：更高階爆發（若湊齊會發動）

主角是鬼牌。連續出牌累積「牌力值」，滿值後可發動 **Joker Time**（10 秒內出牌不消耗，效果加倍）。

## 第一關流程

落地與移動教學 → 單張擊破 ♠2 障礙 → 對子教學（兩名紙偶衛兵）→ 平台與缺口跳躍 → 隱藏凹室（♠A，以跳躍到達）→ 黑桃之眼機關 → 精英紙偶騎士（同花破盾）→ Boss 黑桃 J 三階段 → 通關結算。

Boss 對策：紅圈尖刺地面用跳躍避開；金色蓄力槍用對子打斷；召喚衛兵用同花清場；第三階段攢滿牌力值發動 Joker Time。

## 專案結構

```
/workspace/ace-rift/
  index.html
  README.md
  ace-rift-design.docx
  css/style.css
  js/core.js      工具、輸入、音效、粒子、相機
  js/cards.js     牌型判定、牌堆、卡牌繪製
  js/world.js     關卡、物理、敵人、戰鬥表現
  js/game.js      階段流程、UI、主迴圈
  js/touch-ui.js  觸控按鈕、行動版 HUD 與選單
```

關卡與敵人仍以 Canvas 即時繪製；主角鬼牌使用 `img/` 裡的三視圖立繪（金髮白帽少女）。行動裝置的手牌與按鈕為 HTML 疊層，以避免畫布縮放後難以點選。

開發時可在網址加上 `?touch=1` 強制顯示觸控介面。
